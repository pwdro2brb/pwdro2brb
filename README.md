## 🚀 Sobre mim

Minha trajetória em desenvolvimento começou com a automação de uma atividade administrativa. Conforme identifiquei novos processos que poderiam ser melhorados, passei a desenvolver outras soluções e criei o **Hub de Automações**, uma aplicação corporativa em Python que atualmente:

- centraliza aproximadamente **19 automações**;
- gera uma economia estimada superior a **75 horas mensais**;
- integra sistemas e APIs como **Agilis, Podio, SAP, Outlook e Correios**;
- oferece execução monitorada, histórico compartilhado, dashboard e documentação integrada;
- utiliza controles como catálogo fixo de robôs, validação TLS e armazenamento seguro de credenciais.

Também sou responsável pelo desenvolvimento do **Logistics Hub**, uma plataforma web interna criada com **Next.js, React, TypeScript e SQLite** para gestão de processos logísticos e integração com a API dos Correios.

Minha experiência abrange o ciclo completo de uma solução:

> entendimento do processo → definição da abordagem → desenvolvimento → testes → implantação → documentação → suporte → evolução

Atualmente, busco uma oportunidade de estágio em **Engenharia de Software, Automação ou Integração de Sistemas**, onde possa contribuir com minha experiência prática e evoluir em arquitetura, testes, desenvolvimento em equipe e sistemas de maior escala.

## 💻 Principais projetos

### Hub de Automações

Aplicação desktop em Python desenvolvida para centralizar e executar automações corporativas.

**Principais características:**

- catálogo controlado de automações;
- execução isolada com processos e threads;
- acompanhamento de progresso;
- cancelamento de emergência;
- histórico compartilhado de execuções;
- dashboard de desempenho e saúde operacional;
- classificação e tratamento de erros;
- documentação integrada para os usuários;
- integração com APIs e sistemas corporativos;
- gerenciamento seguro de credenciais;
- distribuição como executável para usuários sem ambiente Python.

> O código-fonte não está disponível publicamente por envolver processos e integrações corporativas.

### Logistics Hub

Plataforma web interna para gestão de postagens, malotes, percursos e custos logísticos.

**Tecnologias e recursos:**

- Next.js, React e TypeScript;
- persistência com SQLite;
- integração server-side com a API dos Correios;
- renovação de token;
- pré-postagem e geração de etiquetas;
- declaração eletrônica de conteúdo;
- rastreamento de encomendas;
- controle de acesso por papéis;
- autenticação com scrypt;
- cookies de sessão `httpOnly`;
- trilha de auditoria;
- validação de payloads;
- testes automatizados.

> Projeto em desenvolvimento e não disponibilizado publicamente por utilizar regras internas de negócio.
